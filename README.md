# がくふよみ

楽譜が日本語の文章みたいに読めるようになるまでの、ピアノ読譜ゲームと相対音感トレーニング。

- **よむ**: ドレミ3音 → 1オクターブ → 音符の長さ・休符・8分音符 → 加線 → ♯♭ → ヘ音記号 → 大譜表(両手同時) → すらすら読み(時間計測)
- **きく**: 高い/低い → ドから聞く(3音→8音) → 調が変わる → メロディ聞き取り → 半音
- **きほん**: 各段階の前に読み方のカード
- スマホ横持ち対応。鍵盤は複数の指で同時押しできる。PCは A S D F G H J K L(白鍵)/ W E T Y U O P(黒鍵)

## 開発
- `node serve.js` → http://localhost:5400 (app/)
- `node tools/make-icons.js` アイコン
- `node tools/build-pages.js` → docs/(GitHub Pages 用 PWA)
